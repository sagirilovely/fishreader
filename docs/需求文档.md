# 需求文档：终端摸鱼小说阅读器（CodeAgent 伪装版）

## 1. 项目背景与目标

### 1.1 背景
用户需要在上班期间偶尔阅读小说放松，但普通阅读器界面特征明显，容易被经过的老板或同事注意到。

### 1.2 目标
开发一个运行在终端里的 TUI 应用：
- 从项目目录自动发现并解析 `.epub` / `.mobi` / `.txt` 小说。
- 用接近“编程 Agent 正在工作”的界面作为主要视觉伪装。
- 小说正文只占终端较小区域，其余大部分区域滚动英文 AI 思考/运行日志。
- 支持方向键翻页，配置化调整显示效果，并支持“老板键”一键隐藏小说。

### 1.3 成功标准
1. 用户进入项目目录后，执行一条启动命令即可阅读。
2. 从老板侧面视角看，屏幕主体是英文滚动日志，小说区域不显眼。
3. 支持三种格式小说，至少 TXT/EPUB 开箱可用，MOBI 降级可用。
4. 阅读进度可保存、可续读。
5. 配置文件可修改字号、阅读区大小、伪装样式、滚动速度等。
6. 老板键按下后 100ms 内切到无中文、无小说内容的纯英文工作界面。

---

## 2. 用户画像与使用场景

### 2.1 用户画像
- 终端用户、程序员，熟悉命令行操作。
- 拥有办公室独立/半独立工位，老板可能从身后经过。
- 阅读内容为中文小说为主，也可能有英文文本。

### 2.2 典型场景
- **场景 A：稳定摸鱼。** 用户启动应用，终端进入 CodeAgent 界面，小说显示在右侧小窗；主区域持续滚动英文日志。用户用 `→` 翻页。
- **场景 B：老板接近。** 用户按老板键，界面立即切换为全屏英文 Agent 日志，无小说和中文。
- **场景 C：重启续读。** 用户下班或关闭终端，再次启动自动恢复上次书籍和位置。
- **场景 D：换书。** 用户通过书籍列表在已扫描小说间切换。

---

## 3. 范围说明

### 3.1 范围内
- TUI 终端阅读器。
- 伪装的 CodeAgent 界面元素。
- TXT / EPUB / MOBI 解析。
- TOML 配置文件。
- 阅读进度持久化。
- 老板键/紧急隐藏。

### 3.2 范围外
- 不做 GUI / 浏览器 / 手机端。
- 不提供书籍下载、在线书源、云同步。
- 不解密 DRM 版权书籍。
- 不在后台真实调用代码生成/执行工具。
- 不通过网络收集任何数据，完全本地运行。

### 3.3 术语澄清
- 需求中 `equb` 按 `epub` 处理。
- 终端“字号/字体大小”指应用内的显示密度档位；终端真实字号由终端软件控制，应用不做跨平台强制修改。

## 4. 功能需求

### FR-1：书籍发现与解析

#### FR-1.1 书籍扫描
- 应用启动时，默认扫描项目根目录下 `books/` 目录（可通过配置修改路径）。
- 递归扫描，支持扩展名：`.epub`、`.mobi`、`.txt`（大小写不敏感）。
- 忽略隐藏文件、隐藏目录、系统临时文件。

#### FR-1.2 TXT 解析
- 自动识别文本编码，至少支持：UTF-8、GBK、GB18030、Big5。
- 识别常见中文章节标题，例如：
  - `第一章 风雪夜归人`
  - `第1章 起源`
  - `第一百二十章 ...`
  - `Chapter 1 ...`
- 无法识别章节时，全书作为单章处理。
- 统一换行符，合并多余空行，按自然段组织。

#### FR-1.3 EPUB 解析
- 读取 `META-INF/container.xml` 定位 OPF。
- 解析 OPF，获取书名、作者、spine 顺序。
- 按 spine 顺序提取 XHTML/HTML 文本，去标签、去脚本/样式、保留段落。
- 分章依据：spine 中的每个内容文档优先作为一章；若内容文档内部含章节标题，可进一步拆分。
- 对无 container.xml 或损坏文件，给出明确错误提示。

#### FR-1.4 MOBI 解析
- 优先使用 `mobi` 依赖进行解包，提取文本/HTML 后复用 TXT/HTML 清理逻辑。
- 若 `mobi` 插件不可用，或文件为 DRM 加密，则该文件标记为“暂不支持”，列表可见但不可读，并显示原因。
- 允许用户配置 “MOBI 解析失败时是否继续通过外部 `kindleunpack` 尝试”。

#### FR-1.5 书籍元数据
- 每本书提取：文件名、格式、书名、作者（后可提取）、章节数、可读状态。
- 文件名作为 book id；同一路径下的文件需稳定。

### FR-2：CodeAgent 伪装界面

#### FR-2.1 界面布局
- 应用启动后全屏显示 CodeAgent 风格界面。
- 顶部：标题栏，显示英文 Agent 名、版本号、会话 id、运行状态。
- 主区域：约占 65%–75%，为英文滚动日志区。
- 阅读区：约占 25%–35%，为小说阅读区。
- 底部：状态栏，用英文显示键盘提示和阅读位置。

ASCII 示意图：

```text
┌──────────────────────────────────────────────────────────────┐
│ ● CodeAgent v0.4.2 — session #8421            [running]     │
├───────────────────────────────┬──────────────────────────────┤
│ 12:03:11 · planning next edit │ reading_notes.md             │
│ $ mypy src/services.py        │                              │
│ ✓ 83/120 tests passed         │  - 第三十三章 夜探           │
│ ... auto scrolling English... │  - 只见那黑衣人...          │
│                               │                              │
│                               │  buffer: 37.2%               │
├───────────────────────────────┴──────────────────────────────┤
│ [b]oss mode   ←/→ page   ↑/↓ line   l library   q quit      │
└──────────────────────────────────────────────────────────────┘
```

#### FR-2.2 英文滚动日志
- 日志区持续自动滚动，新日志追加到底部。
- 内容为随机但不重复度过高的英文 AI 思考/运行日志，包括但不限于：
  - planning / reasoning 文本
  - shell 命令和输出
  - 测试摘要
  - 代码搜索结果
  - git 状态摘要
  - 打字机式的思考片段
- 具有时间戳、显著但不过分的颜色标记（如 `[INFO]`、`[WARN]`、`[OK]`）。
- 滚动速度可配置；默认约 0.8–1.5 秒产生一条日志。
- 单条日志长度限制在 120 个终端显示宽度内。

#### FR-2.3 小说阅读区伪装样式
- 小说文本使用伪装样式渲染，默认样式为 Markdown 列表/引用样式，视觉上更像工作笔记或阅读摘录。
- 可选样式包括：
  - `markdown`（默认）：`- 正文` 或 `> 引用正文`
  - `comment`：`# 正文`
  - `docstring`：首行和末行 `"""`，中间正文
- 阅读区标题类似 `draft_note.md`、`notes/tmp_review.md`，不使用小说中文标题。
- 阅读区颜色使用暗色/次要色，降低注意力吸引。

#### FR-2.4 底部状态栏伪装
- 显示内容全部为英文，示例：
  - `buff 37.2% | scroll 124/401 | [b]oss [l]ibrary [q]uit`
- 不显示中文书名或中文章节名。

### FR-3：阅读控制

| 按键 | 功能 |
|---|---|
| `→` / `Space` | 下一页 |
| `←` | 上一页 |
| `↑` | 向上滚动一行 |
| `↓` | 向下滚动一行 |
| `PgUp` / `PgDn` | 上/下一页 |
| `l` | 打开书籍列表（伪装为 Open recent files） |
| `n` / `p` | 下一章 / 上一章 |
| `b` | 老板键：切换全屏英文伪装模式 |
| `q` | 退出并保存进度 |
| `Esc` | 关闭弹窗；或根据配置可作老板键 |

补充：
- 书籍列表弹窗显示英文标题 `Open recent files`，列表项优先显示英文文件名；书名可存在于 secondary 行。
- 当到达章节末尾时继续翻页自动进入下一章；到书籍末尾时显示 `EOF` 提示。
- 分页按终端宽高、阅读区宽高、字体密度档位动态计算。

### FR-4：配置系统

#### FR-4.1 配置文件
- 使用 TOML 格式，文件名为 `fish.toml`，位置在项目根目录。
- 首次启动时自动生成带注释的默认配置。
- 支持启动参数 `--config <path>` 指定其他位置。

#### FR-4.2 默认配置项

```toml
[books]
scan_dirs = ["books"]              # 扫描目录，可多个
extensions = [".epub", ".mobi", ".txt"]

[reader]
font_size = "medium"               # small | medium | large，模拟字号/密度
line_spacing = 0                   # 行间额外空行，0/1/2
paragraph_spacing = 0              # 段落间空行，0/1/2
reader_width = "30%"               # 阅读区占比
reader_position = "right"          # right | bottom，本版本默认 right
novel_style = "markdown"           # markdown | comment | docstring
resume_last = true                 # 启动自动续读

[disguise]
agent_name = "CodeAgent"
agent_version = "0.4.2"
log_interval_min = 0.8             # 秒
log_interval_max = 1.5             # 秒
log_style = "english"              # 只允许英文日志
status_line = "minimal"
boss_key = "b"
full_hide_chinese = true           # 老板模式过滤 CJK 字符

[theme]
log_level_color = true
reader_color = "gray"
accent = "green"

[progress]
file = ".fish_progress.json"
autosave_on_page = true
```

#### FR-4.3 font_size 说明
- `small`：阅读区使用更紧凑的行距，每页容纳更多行。
- `medium`：默认。
- `large`：行距加大、段落间距加大，每页容纳更少行。
- 应用不尝试修改终端真实字体大小；真实字号请使用终端的缩放快捷键。

### FR-5：老板键与紧急伪装

- 按下老板键后，立即切换为 `boss mode`。
- `boss mode` 行为：
  1. 隐藏小说阅读区。
  2. 主日志区扩展到 100% 宽度。
  3. 所有 UI 文本切换为英文，过滤/隐藏 CJK 字符。
  4. 如当前恰好打开弹窗，立即关闭弹窗。
- 再次按下老板键恢复原状态；恢复后继续原阅读位置。
- 老板键响应优先级高于其他按键。
- 本版本不提供 `--stealth` 参数；老板模式通过按键手动切换。

### FR-6：进度持久化

- 进度文件默认 `.fish_progress.json`，位于项目根目录。
- 每本书记录：
  - `book_id`
  - `chapter_index`
  - `char_offset`（当前页首字符在文本中的绝对偏移量）
  - `scroll_line`
  - `updated_at`
- 翻页、换章、退出时保存，`autosave_on_page = false` 时可仅在退出保存。
- 启动时若存在进度且 `resume_last = true`，自动打开上次书籍并跳到上次位置。
- 若书籍文件被移动/删除，进度记录标记为失效，不崩溃。

### FR-7：错误处理与降级

- 不支持的 MOBI/DRM：列表标记 `unsupported`，不阻塞其他书。
- TXT 编码无法确认时：按配置的候选编码顺序尝试，失败后给出可读提示。
- 终端窗口过小（如高度 < 12 或宽度 < 40）时，提示用户放大终端。
- Textual 或其他依赖缺失时，启动脚本提示安装命令。

## 5. 非功能需求

### NFR-1：隐蔽性
- 默认界面主体必须为英文日志。
- 中文内容在非老板模式下仅出现在阅读区；状态栏、标题栏、弹窗标题不使用中文。
- 老板模式下界面不得出现 CJK 字符。

### NFR-2：性能
- 空闲时 CPU 占用应保持低位，避免风扇狂转（老板可听见）。
- 10MB 级 TXT 解析应在可接受时间内完成（简化目标：3 秒内）。
- 翻页响应时间 < 100ms。

### NFR-3：兼容性
- 优先支持 macOS / Linux 现代终端（iTerm2、Terminal.app、GNOME Terminal、kitty 等）。
- Windows Terminal 作为次优先级；CJK 宽度按其 `wcwidth` 处理。
- Python 版本：3.11+。

### NFR-4：隐私
- 应用完全本地运行，不上传任何数据。
- 不读取项目目录以外的文件，除非用户显式在配置中指定路径。

### NFR-5：可测试性
- 解析、分页、配置、编码识别、伪装日志生成等核心模块可脱离 TUI 单元测试。

## 6. 用户操作流程

### 6.1 首次启动
1. 将小说文件放入 `books/`（或配置扫描目录）。
2. 在项目目录执行 `python run.py`。
3. 应用生成 `fish.toml`，扫描书籍，显示书籍列表。
4. 用户选择一本书，进入阅读界面。

### 6.2 日常启动
1. 执行 `python run.py`。
2. 自动恢复上次书籍和位置。

### 6.3 老板经过
1. 眼角扫到老板或听到脚步声。
2. 按 `b`。
3. 界面变为全屏英文 Agent 日志。
4. 老板离开后，再按 `b` 恢复阅读。

---

## 7. 验收标准

1. 放入 UTF-8 中文 TXT，可启动并正确分页阅读。
2. 放入 GBK 中文 TXT，可启动并正确分页阅读。
3. 放入 EPUB，可提取文本并阅读。
4. 放入无 DRM MOBI，可读或给出明确不可读原因。
5. 默认界面中，英文日志区面积 ≥ 60%，阅读区 ≤ 40%。
6. 方向键翻页正确，进度保存后重启续读。
7. `fish.toml` 修改字体密度、阅读区占比、日志速度后生效。
8. 按老板键后，界面无中文、无小说，再次按下可恢复阅读。

## 8. 风险与已确认决策

### 8.1 风险
| 风险 | 影响 | 缓解 |
|---|---|---|
| MOBI 解析库不维护或 Python 版本不兼容 | MOBI 不可用 | 降级方案：跳过 MOBI、提示用户转 TXT/EPUB，或可选调用 `kindleunpack` |
| 终端 CJK 宽度计算不一致 | 对齐错乱 | 统一使用 `unicodedata.east_asian_width` + 终端宽度 API，不依赖字体猜测 |
| 假日志长期重复引起老板怀疑 | 伪装失败 | 日志生成器用模板 + 组合 + 随机参数，避免短时间重复 |
| Textual 在小终端/Windows 兼容性问题 | 无法启动 | 运行时检测终端尺寸并给出明确提示；README 记录兼容环境 |
| 中文书名/章节在周边 UI 泄露 | 隐蔽失败 | 阅读区外只显示英文，书籍列表可为 `book_003.txt` 样式 |

### 8.2 已确认决策
1. 阅读区默认位置：右侧，约占 30%。
2. 老板键默认值：`b`。
3. 小说伪装默认样式：`markdown`。
4. 默认扫描目录：`books/`。
5. 不提供 `--stealth` 参数，老板模式通过按键手动切换。
